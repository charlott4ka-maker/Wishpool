# Wishpool landing

Static page (no build step): open `index.html` or serve the folder
(`python3 -m http.server`). Styled with the Mini App's tokens: Montserrat
500-800 (self-hosted in `assets/fonts`), black page, #161618 cards,
#2E7DF6 blue, no outlines on blocks, image stickers with the white rim
baked in (`assets/stickers`, same files as `web/public/stickers`).

`assets/app-*.webp` are real screenshots of the app (390x844 @2x).
Not deployed anywhere: Vercel only serves `web/dist`.
