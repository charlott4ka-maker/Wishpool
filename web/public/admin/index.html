Wishpool Admin

Вход

Почта, с которой ты входишь в приложение. Доступ есть только у админов.

Нет доступа

Этот аккаунт не админ. Добавь его почту в переменную ADMIN_EMAILS на Vercel.

Изменения попадают в приложение примерно за минуту, при следующем открытии.

Баннеры

Полоска под заголовком на вкладке «Желания». Показывается первый включённый баннер, подходящий пользователю. Если пользователь закрыл баннер крестиком, он больше его не увидит.

Тексты приложения

Найди текст по словам или ключу и поменяй. Пустое поле = стандартный текст. Без тире в текстах.

Стикеры

Нажми на стикер, чтобы скрыть его из выбора в приложении или вернуть. Старые желания со скрытым стикером продолжат его показывать.

Новый стикер

PNG или WebP с белой обводкой и прозрачным фоном, как у остальных. Квадрат, лучше 512×512. Имя латиницей, например teddy. Перезалить под тем же именем нельзя: удали и загрузи с новым.

Хранилище фото (R2) не настроено на сервере, загрузка не сработает.
